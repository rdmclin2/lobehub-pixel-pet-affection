# 快捷调用面板（T-2849）

桌宠旁边的一个小菜单，放常用操作，其中有 **检查更新…**。样式参照 LobeHub 在 macOS 上的应用菜单（About / Check for updates… / Preferences… ⌘, / Quit ⌘Q）：分组之间有细线，左边是图标，右边是快捷键，指针或方向键所在的行用强调色填充。亮色 / 暗色跟随系统（或 设置 → 外观 里固定的主题）。

## 怎么打开 / 关闭

| 打开 | 说明 |
| --- | --- |
| 在她身上 **右键** | 面板出现在点击处（像右键菜单）；放不下时向左 / 向上翻转，始终完整地留在屏幕内（她贴边、半出屏时也一样） |
| 触屏上 **长按** 她 0.5 秒 | 同右键 |
| 全局快捷键 **⌘⌥P**（macOS）/ **Ctrl+Alt+P**（Windows、Linux） | 在任何应用里都能按；面板出现在她旁边（左侧放不下就放右侧）；她被隐藏时出现在鼠标所在屏幕的中间 |
| 托盘 → **快捷调用面板…** | 在鼠标处打开 |

关闭：**Esc**（筛选框有字时第一次 Esc 先清空）、点面板以外的地方（她的窗口或别的应用）、执行某一行之后、再按一次快捷键。面板只有一个窗口，反复打开 / 关闭不会留下第二个。

快捷键被占用时：⌘⌥P / Ctrl+Alt+P 被别的应用占了就自动改用 **⌘⌥⇧P / Ctrl+Alt+Shift+P**；两个都被占用时不注册快捷键，应用照常运行，面板底部会写「快捷键被占用，右键她也能打开」。它也不会和「快捷键唤起语音对话」抢同一个组合（设置窗口不允许把语音快捷键设为 Ctrl+Alt+P）。

> **右键行为的变化**：以前右键 / 长按她直接打开设置窗口；现在打开快捷调用面板，第三行就是 **偏好设置…**（再点一下打开设置窗口）。⚙ 按钮和 Ctrl/⌘ + , 仍然一步打开设置窗口。

## 面板里有什么

| 分组 | 行 | 右侧提示 | 做什么 |
| --- | --- | --- | --- |
| 1 | 关于 Pixel Pet | 版本号（如 v0.24.0） | 打开 设置 → 版本与更新 |
| 1 | 检查更新… | 检查中时显示「检查中」 | 调用托盘「检查更新」用的同一个 `Updater.checkNow()`，结果显示在面板里（见下表） |
| 2 | 偏好设置… | ⌘, / Ctrl+, | 打开设置窗口 |
| 3 | 和她聊天 | — | 显示她并打开聊天框（她被隐藏时不显示这一行） |
| 3 | 重置姿势 | ⌘⇧R / Ctrl+Shift+R | 同工具栏 ↺（仅 VRM 形象显示） |
| 3 | 隐藏桌宠 / 显示桌宠 | — | 隐藏她的窗口；隐藏后用快捷键或托盘打开面板，这一行变成「显示桌宠」 |
| 4 | 退出 | ⌘Q / Ctrl+Q | 退出应用 |

右侧的快捷键在面板有焦点时也能直接按。键盘：打开后直接打字即可筛选（中文、英文都行，如「更新」「update」「设置」「quit」），↑↓ 移动高亮（跳过分隔线），↩ 执行。

## 检查更新的反馈

点 **检查更新…** 后面板不关，结果出现在它下面；有后续操作时，下面多一行可以点（也能用 ↓ ↩ 选中）。

| 状态 | 面板显示 | 后续 |
| --- | --- | --- |
| 检查中 | 正在检查更新… · 当前版本 v0.24.0（转圈） | — |
| 已是最新 | 已是最新版本 · 当前版本 v0.24.0 | — |
| 有新版本，正在下载（Windows / macOS） | 发现新版本 v0.25.0 · 正在后台下载，下载好后会提示你立即更新 | — |
| 已下载好 | 新版本 v0.25.0 已下载好 · 立即更新会重启桌宠（约 2 秒），数据都会保留 | **立即更新** |
| 有新版本，需手动下载（Linux，或 macOS 从 DMG / 下载文件夹运行） | 发现新版本 v0.25.0 · 这个版本需要到下载页下载安装（或具体原因） | **前往下载页** |
| 失败 | 检查更新失败 · 更新服务器返回 500 / 连不上更新服务器，检查一下网络（…） | **重试** |
| 开发版（从源码运行 / `PIXELPET_NO_UPDATE=1`） | 当前版本不检查更新 · 开发版（从源码运行）或已关闭更新时不会检查；当前版本 v0.24.0 | — |

找到的新版本（下载中 / 已下载 / 需手动下载）之后每次打开面板都还在，随时可以点「立即更新」「前往下载页」。结果出来之前就关掉了面板的话，她会在气泡里说结果，例如「（已是最新版本：当前版本 v0.24.0。）」「（检查更新失败：更新服务器返回 503。右键我打开快捷调用面板，点「重试」。）」；有新版本时她本来就会说（原有行为）。

## 实现

- `src/core/quick-panel.js`：行与分组、筛选、↑↓、快捷键匹配、更新状态 → 文案、面板位置（不依赖 Electron，`test/quick-panel.test.js`）。
- `src/main/quick-hotkey.js`：全局快捷键及备选 / 降级。
- `src/main/quick-panel.js`：面板窗口（无边框、置顶、sandbox + contextIsolation，只建一次，之后显示 / 隐藏），失焦关闭，检查更新的反馈。
- `src/main/quick-preload.js`、`src/renderer/quick/`：面板页面（`--lobe-*` 令牌）。
- `src/main/main.js`：每一行对应的操作（`quickActions`）、IPC `quick-open` / `quick-dismiss`、托盘项。

验证：`npm test`；`xvfb-run -a -s "-screen 0 1280x800x24" node e2e/run.js quickpanel`（录屏、截图在 `out/e2e/quick/`）。开发时可用 `PIXELPET_UPDATE_TEST=1` + `PIXELPET_UPDATE_FEED=<本地服务>` 让检查更新走真实流程。
